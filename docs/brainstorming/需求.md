# 需求说明

## 核心体验
- 通过 React 页面呈现一个以公园为主题的 3D 场景，主角是一只水豚，周围有草地、路径、树木或长椅等低多边形元素，氛围轻松。
- Canvas 内所有 3D 渲染由 `@react-three/fiber` 驱动，配套 `@react-three/drei` 辅助环境光、阴影与粒子。
- 角色持续受键盘控制，可执行移动、跳跃、蹲伏/爬行/趴下、舞蹈等动作，并在动作之间保持自然过渡。

## 交互行为
- 键盘控制方案：
  - `W/A/S/D` 驱动前后左右移动（支持摄像机相对方向或世界坐标）。
  - `Space` 发起跳跃，结束后落地带轻微震动粒子。
  - `Shift` 切换到蹲伏/爬行姿态，按键释放回到站立。
  - `C`、`V`、`B` 等自定义快捷键用于「趴下」「站立」「跳舞」或其他状态。
- 状态通过统一 state machine 管理：`idle`、`walk/run`、`jump`、`crouch/crawl`、`dance`，由 `useFrame` 逐帧插值及 `useAnimations`（如使用 GLTF）驱动动画。
- 动作反馈包括尾巴、头部、身体随节奏摆动、跳舞时灯光/粒子脉冲。

## 场景与视觉
- 地面由渐变/贴图的平面构成，支持柔和阴影；使用 `Environment` 或 `Sky` 提供户外光照。
- 场景中可添加 `Sparkles`、飞舞的粒子带或柔光效果增强魔法感。
- 相机由 `OrbitControls` 或自定义逻辑控制，默认跟随角色，允许轻微旋转/缩放。

## UI 与提示
- 页面底部悬浮状态条，实时显示当前动作（例如「行走」「跳跃」「跳舞模式」）。
- 右上角显示按键提示、操作指南开关；按住某键时对应图示高亮。
- 鼠标悬停/按键触发时可短暂显示提示泡泡，帮助用户理解控制。

## 技术限制与扩展性
- 所有逻辑都在 React 中处理，未来可扩展为更多互动（例如触摸、道具）。
- 使用 Vite 或 CRA 初始化项目，便于快速迭代与部署。
