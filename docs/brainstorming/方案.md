# 方案设计

## 技术选型
- 基础框架：React + Vite/CRA，保持单页结构，方便绑定状态、UI 和 3D Canvas。
- 3D 渲染：`@react-three/fiber` 提供 `<Canvas>` 与 `useFrame`，封装 `three.js` 渲染生命周期。
- 工具集：`@react-three/drei` 包括 `OrbitControls`、`Environment`、`Sparkles`、`useAnimations` 等，减少重复开发；`zustand`/`useState` 可用于共享输入状态。
- 控制：自定义 `useKeyboardControls` hook（或 `@react-three/drei` 的 `KeyboardControls`）统一监听 `keydown/keyup`，输出 `movementState`、`postureState`、`danceMode`。

## 场景与角色
- 构建 `CapybaraScene` 组件，内部包含：
  - `Environment` 提供全局光照和天空。
  - `Floor` 采用 `mesh` + `shadowMaterial` 表现草地，用 `NormalMap`/渐变突出纹理。
  - 几组 `Tree/Bench` 简化模型构建公园氛围。
  - `CapybaraModel` 角色：可使用 GLTF（带基本骨骼）或简单几何+组。
  - `Sparkles` 等粒子组件围绕角色，用 `movementState` 驱动颜色/强度。
- 角色运动通过 `useFrame` 拟合位置/旋转，跳舞时触发 `pose` 间的 lerp，舞步可绑定 `sin/cos` 摆动。
- 使用 `useAnimations`（若采用 GLTF）或 `useRef` 手动修改 `mesh` 变换，实现 `jump`、`dance` 等动作。

## 控制与状态流
- `useKeyboardControls` hook 返回 `{ forward, backward, left, right, jump, crouch, danceMode }`。
- 另设 `CapybaraStateMachine` hook，接收输入并输出 `movementState`（idle/walk/run）、`postureState`（stand/crouch/prone）、`animationState`（dance/jump）。
- `CapybaraModel` 订阅状态并驱动相应 animation clip 或 transform interpolation。
- `useFrame` 负责根据 `movementState` 对角色位置进行平滑过渡，并在落地时触发 `SparkleTrail` 粒子。
- 控制状态同时更新 HUD，确保 UI 与动作同步。

## UI 结构
- 主页面分为 `Canvas` 区域与 UI overlay：
  - `StatusBar`（底部）：文本表示当前动作与说明徽章。
  - `ControlHintPanel`（右上）：显示 WASD/Space/Shift/C/V/B 图标，高亮当前按下的键。
  - `ActionToggle`：如打开/关闭舞蹈效果或切换摄影机角度。
- UI 与 Canvas 共享 `useControlsState`（例如 React Context/`zustand`），保持低延迟同步。

## 扩展与后续
- 可加入简单物理（`use-cannon`）以增强跳跃、落地感。
- 提供额外按键绑定（如 `E` 交互）或多角色支持。
- 未来可用 `react-spring` 统一 UI/动画过渡，用 `useEffect` 绑定节奏变化。
